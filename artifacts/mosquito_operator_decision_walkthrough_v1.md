# Mosquito Operator Decision Walkthrough

1. Intake received: read the WhatsApp message and confirm the pilot number.
2. Operator review: identify city, neighborhood, home type, problem area, timing, and optional media.
3. Contradiction check: mark missing location, conflicting details, unsupported area, unsafe request, or impossible guarantee.
4. PASS/HOLD/BLOCK assignment: choose one state and write a short decision reason.
5. Replay logging step: record operator ID, intake timestamp, decision reason, contradiction flags, next manual action, and replay reference.
6. Next manual action: reply manually with scheduling, clarification, or bounded refusal.
