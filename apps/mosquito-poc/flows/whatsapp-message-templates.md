# WhatsApp Message Templates

Templates for Make.com WhatsApp integration. Copy-paste ready.

## Initial Greeting (After QR Scan)

```
שלום! תודה שסרקת את הקוד שלנו.
אנחנו כאן לעזור עם יתושים. בואו נבין את המצב שלכם.

איפה זה מורגש?
1. רגליים
2. ידיים
3. גב
4. צוואר
5. כל הגוף

(אפשר לבחור יותר מאחד: 1,3 למשל)
```

## LOW Score Output (lead_score < 31)

```
תודה על המידע. נראה שהמצב לא דחוף כרגע.
נשלח לכם מידע מועיל על מניעת יתושים.
לשירות דחוף - צרו קשר ישירות.
```

## REVIEW Output (31 ≤ lead_score < 61)

```
תודה! המצב שלכם מתון.
נשלח לכם טיפים מותאמים למניעת יתושים.
אם המצב יחמיר - נהיה כאן.
```

## HIGH_PRIORITY Output (lead_score ≥ 61)

```
תודה על הפרטים. נראה שיש לכם בעיה משמעותית עם יתושים.
אנחנו יכולים לתאם התקנת מלכודות מקצועית.

המחיר: 500 ש"ח (כולל התקנה וחודש טיפול ראשון)
התשלום: ביט / פייפאל / העברה בנקאית

אשרו תשלום ואתאם זמן התקנה.
```

## Post-Payment Scheduling Prompt

```
תודה! ההתקנה תתבצע ב[תאריך] על ידי [שם טכנאי].
הטכנאי יגיע עם מלכודות ויתקין במקומות האופטימליים.
זמן התקנה: כ-30 דקות.

שאלות? צרו קשר.
```
