# Data Files

## leads.csv
Stores prospective customer lead information. Tracks initial contact details including when the lead was generated, where it came from, geographic location, communication frequency, and a preliminary scoring/qualification status.

## installs.csv
Records mosquito trap installations linked to converted leads. Contains installation dates, trap quantities deployed, installer details, and current installation status.

## renewals.csv
Tracks service renewal and follow-up schedules for active customers. Records the date of last service, scheduled next follow-up dates, and renewal status.
