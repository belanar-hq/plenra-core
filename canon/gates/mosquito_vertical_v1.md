# mosquito_vertical_v1

Static deterministic Decision Gate for mosquito trap subscription management in Petah Tikva via WhatsApp.

- Reuses existing apps/mosquito-poc assets without overwriting.
- Implements deterministic gate contract with required fields validation.
- Blocks adaptive routing, autonomous learning, and predictive risk.
- Preserves WhatsApp templates and Petah Tikva geographic scope.
- Links existing POC files in lineage for traceability.
